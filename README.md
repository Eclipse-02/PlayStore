# PlayStore

## Deskripsi Aplikasi

PlayStore adalah aplikasi clone Google Play Store yang dikembangkan untuk platform Android menggunakan Java.
Aplikasi ini dirancang untuk memberikan pengalaman navigasi yang mirip dengan Play Store asli untuk menjelajahi berbagai kategori aplikasi,
melihat rincian aplikasi secara mendalam, serta mensimulasikan proses instalasi dan pengelolaan aplikasi. Proyek ini mengimplementasikan konsep Material Design 3,
arsitektur UI yang responsif untuk ukuran layar smartphone dan tablet, serta manajemen data lokal menggunakan SharedPreferences.

## Fitur Utama

- **Apps & Games Explorer**: Menampilkan feed aplikasi yang dikategorikan seperti *Featured*, *Recommended*, dan *Suggested* dengan tata letak RecyclerView yang dinamis.
- **Deep App Insights**: Menyediakan informasi lengkap aplikasi mencakup rating, ulasan pengguna, ukuran file, jumlah unduhan, serta galeri tangkapan layar (*screenshots*) yang interaktif.
- **Search & Filter System**: Fitur pencarian aplikasi yang efisien dengan dukungan eksplorasi kategori melalui sistem *chip* yang interaktif.
- **Installation Simulation**: Fitur untuk mensimulasikan proses *Install* dan *Uninstall* aplikasi dengan status yang tersimpan secara lokal.
- **Wishlist & Bookmarks**: Memungkinkan pengguna untuk menandai aplikasi favorit ke dalam *wishlist* agar dapat diakses dengan mudah di kemudian hari.
- **Responsive UI Layouts**: Antarmuka yang adaptif dengan dukungan *Bottom Navigation* untuk smartphone dan *Navigation Rail* untuk pengalaman layar lebar di tablet atau perangkat *foldable*.
- **Advanced Media Handling**: Integrasi Glide untuk pengoptimalan pemuatan gambar dan PhotoView untuk fitur zoom pada gambar tangkapan layar aplikasi.
